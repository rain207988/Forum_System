# Forum System 升级说明

## 1. 这次升级解决了什么

本次改造的目标不是只把一个课堂练习项目“修到能跑”，而是把它推进成一个更接近真实论坛站点的 Spring Boot 项目骨架。核心升级集中在以下几个方向：

- 补全论坛核心链路：帖子列表、帖子详情、发帖、编辑、删除、回复、点赞、个人主页、用户中心。
- 新增站内私信系统：支持发送私信、收件箱、未读计数、已读标记、回复私信。
- 打通前后端接口：修复静态页面中大量“前端已经调用、后端却不存在”的接口断点。
- 提升工程化含量：引入缓存、健康检查、参数校验、安全密码加密、H2 测试数据库、自动化测试。
- 补足上线准备项：支持环境变量数据库配置，新增监控端点，提供可复现测试环境。

## 2. 功能升级清单

### 2.1 论坛业务功能

- 首页与版块页统一走帖子查询接口，支持关键词搜索。
- 个人主页支持查看指定用户信息和该用户的发帖记录。
- 帖子详情页支持：
  - 查看作者信息
  - 点赞
  - 回复
  - 编辑/删除自己的帖子
  - 向作者或回复者发送私信
- 用户中心支持：
  - 修改昵称
  - 修改邮箱
  - 修改手机号
  - 修改个人简介
  - 修改头像地址
  - 修改密码

### 2.2 站内私信

新增完整站内信模块：

- `message/send`：发送私信
- `message/getAll`：获取当前用户收件箱
- `message/getUnreadCount`：获取未读数量
- `message/markRead`：标记已读
- `message/reply`：基于收到的消息回复

前端首页右上角小铃铛已经与这些接口联动：

- 未读消息显示红点
- 点击消息自动标记已读
- 支持在弹窗中直接回复

## 3. 新增技术栈与工程化增强

这次为了提升项目“含金量”，我额外引入了几类更像真实项目会出现的技术能力：

### 3.1 安全与认证

- `spring-security-crypto`
  - 使用 `BCrypt` 作为新密码加密方案。
  - 兼容旧项目里已经存在的 MD5+salt 密码，用户登录后可自动升级为 BCrypt。

### 3.2 健康检查与运维能力

- `spring-boot-starter-actuator`
  - 开放 `health`、`info`、`metrics` 端点。
  - 更适合后续接入上线监控与平台探活。

### 3.3 缓存能力

- `spring-boot-starter-cache`
- `Caffeine`
  - 对版块列表、用户信息等读多写少的数据做了本地缓存支持。
  - 便于后续平滑升级到 Redis 方案。

### 3.4 测试能力

- `H2 Database`
  - 新增 `test` 环境配置。
  - 使用内存数据库初始化论坛表结构和测试数据。
  - 不再依赖本机 MySQL 才能跑测试。

### 3.5 参数校验与异常治理

- `spring-boot-starter-validation`
- 统一服务层参数校验工具 `ServiceValidationUtils`
- 统一异常返回结构 `AppResult`

## 4. 关键后端改造点

### 4.1 重构和新增的核心接口

- `UserController`
  - 登录、注册、退出
  - 获取用户信息
  - 修改资料
  - 修改密码

- `ArticleController`
  - 查询全部帖子 / 板块帖子 / 用户帖子
  - 发帖
  - 详情
  - 编辑
  - 删除
  - 点赞

- `ArticleReplyController`
  - 新增帖子回复
  - 查询帖子回复列表

- `MessageController`
  - 完整站内信能力

### 4.2 Service 层增强

- `UserServiceImpl`
  - 密码升级策略
  - 用户资料更新
  - 密码修改

- `ArticleServiceImpl`
  - 支持关键词检索
  - 支持按用户查询帖子
  - 修复回复数更新逻辑

- `MessageServiceImpl`
  - 新增完整私信业务逻辑

### 4.3 MyBatis 层修复

修复了原项目多个会直接导致项目启动失败的问题：

- `ArticleReplyMapper.xml` 原始 XML 不完整，已重写
- `ArticleReplyExtMapper.xml` 命名空间错误，已修复
- 新增 `MessageExtMapper.xml` 支持站内信联表查询
- `ArticleExtMapper.xml` 增强为支持：
  - 帖子作者信息
  - 板块信息
  - 关键词搜索
  - 按用户查询帖子

## 6. 如何启动项目

### 6.1 本地开发启动

默认使用 MySQL，支持通过环境变量覆盖数据库配置：

- `FORUM_DB_URL`
- `FORUM_DB_USERNAME`
- `FORUM_DB_PASSWORD`

启动命令：

```bash
./mvnw spring-boot:run
```

默认端口：

```text
http://localhost:58080
```

### 6.2 运行测试

测试会自动使用 H2 内存数据库：

```bash
./mvnw test
```

## 7. 这次升级后项目更像什么级别

升级后的项目更接近“简历可讲述的论坛系统项目”而不是“只有 CRUD 的课程作业”，因为它已经具备：

- 真正的用户互动能力
- 更完整的论坛链路
- 一定程度的上线运维意识
- 更合理的安全设计
- 可复现的自动化测试环境

## 8. 后续还能继续扩展的方向

如果你还想把这个项目继续升级成更强的求职项目，下一步建议优先做：

- Redis 会话与缓存
- 管理员后台
- 内容审核与封禁
- 文件上传到 MinIO / OSS
- WebSocket 即时消息提醒
- Elasticsearch 搜索
- Docker Compose 一键部署

这些我这次没有硬塞进去，是为了先保证当前版本已经稳定、能讲、能跑、能测、能继续扩。
